# Discord Apple Music Integration (DAMI)

Ce projet permet d’intégrer Apple Music à Discord via Rich Presence.  
Il affiche en temps réel les informations de lecture (titre, artiste, album) directement sur ton profil Discord.

Le projet est développé en C++ et utilise l’API Discord RPC pour mettre à jour l’activité en fonction de la musique jouée sur Apple Music.

**Cette application fonctionne uniquement avec Apple Music et Discord sur Windows.**

### Fonctionnalités

- Affichage du morceau en cours sur Discord
- Synchronisation avec Apple Music
- Mise à jour dynamique du statut (Rich Presence)
